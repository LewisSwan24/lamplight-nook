## 简体中文 (zh-CN)

### 名称

小灯屋

### 简短介绍

把 Claude 做的长任务，变成一家像素小咖啡馆里店员们的日常。

### 介绍

小灯屋要用你电脑上的 Claude Code 和你自己的 Anthropic API Key。店员做出来的网页、文件和图片都由 AI（Anthropic 的 Claude）生成，用之前请看过。

你在柜台上写下想做的事：一个小网页、一封信、一张表、一份计划、一本相册……店员们就开工了。
阿灯拿主意，帮手们出门查资料、定样子、做检查；黑板上写着 Claude 真正的计划，做完一项划掉一项。
遇到要你拿主意的地方，他们会来问你；删文件这类找不回来的事，一定先问过你，默认是“先不要”。

- 真实的进度：店员们的一举一动都来自 Claude 的真实事件，不是动画演给你看。
- 随时能查：点柜台、黑板或工具栏，就能看到用了多久、做到哪一步、谁在做什么，也能插句话或者喊停。
- 点什么都有回应：窗户、时钟、灯、小猫和店员，点了都有反应，而且不花钱。
- 东西交给你：做好的东西放进作品架，随时打开，也可以再改一轮，旧版本留着。
- 可以交材料：把文件拖到柜台上，店员们只用副本，原件不动。
- 做 Office 文件和图片：Word、Excel、PPT、PDF、图表和海报都能做，也能改你交来的文件。
- 可以连上你的工具：网盘文件夹、只读日历和邮件草稿。每种连接先说清能做什么，每一单由你勾选，改动外面东西之前一定先问你。
- 花多少心里有数：每次开工有花费上限，到了就停下来问你。
- 小店会长大：做过什么，店里就添什么，相应的街坊也会来串门。墙纸、窗帘和地毯可以自己布置。
- 中文和英文两种界面。

### 使用前需要

- 电脑上装好 Claude Code（小灯屋会一步步带你装）。
- 一把你自己的 Anthropic API Key，在应用里粘贴即可，加密保存在这台电脑上。费用按你自己的 Key 计费，小灯屋不另外收费。
- 订阅了 Claude Max、Ultra 或 Team 的话，方案每月附带的 Claude API 赠送额度也可以用在小灯屋。做法是在 claude.ai 的账单设置里把额度关联到一个 Claude Console 组织，再用这个组织创建的 API Key。

### 隐私

小灯屋不收集你的任何数据，没有统计、没有广告，也没有我们的服务器。你的设置、Key 和作品都只在你的电脑上。

委托的内容会通过 Claude Code、用你自己的 Key 发给 Anthropic 处理。委托单上勾了连接的话，店员从网盘文件夹和日历里读到的内容也会一起发过去。连了日历，这台电脑会按你给的订阅地址去取日程。

分享作品和寄明信片，都是存成一个文件，由你自己发给别人。分享的文件只带作品本身，文件夹路径和像 Key 的字符串都会抹掉。明信片只带小店的样子和你的称呼。

家里网络的开关默认关着。打开以后，只有配对过的手机和电脑能连进来，每条消息都加密，也不经过我们的服务器。

## English (en)

### Name

Lamplight Nook

### Short description

Long AI tasks from Claude, played out as a day in a small pixel-art café.

### Description

Lamplight Nook needs Claude Code on your computer and your own Anthropic API key. The pages, files and pictures the staff make are generated by AI (Anthropic's Claude): check them before you use them.

Write what you want at the counter: a small web page, a letter, a table, a plan, a photo album... and the staff get to work.
Wick decides what to do, helpers go out to look things up, pick a look and check the work, and the blackboard shows Claude's
real plan, ticking items off as they are done. When something is yours to decide, they come and ask; anything that can't be
undone, such as deleting files, always waits for you, and the default is "not now".

- Real progress: every move the staff make comes from Claude's real events, not a canned animation.
- Look any time: the counter, the blackboard or the toolbar show how long it has taken, how far it has got and who is doing what, and you can add a word or call it off.
- Everything answers a click: the windows, the clock, the lamps, the cat and the staff all respond, and it costs nothing.
- Work you keep: finished pieces go on the works shelf, ready to open, and can go through another round with the old version kept.
- Hand over files: drop them on the counter; the staff work on copies and never touch the originals.
- Office files and pictures: Word, Excel, PowerPoint, PDF, charts and posters, and edits to the files you hand over.
- Connect your own tools: a synced folder, a read-only calendar and email drafts. Each connection says what it can do, you tick it for each commission, and anything that changes something outside always asks first.
- Spending you can see: each commission has a spending cap, and the shop stops and asks when it is reached.
- A shop that grows: what you make shows up in the shop, and the neighbours who care about it drop in. You can choose the walls, curtains and rug.
- In English and Simplified Chinese.

### What you need

- Claude Code installed on the computer (the shop walks you through it).
- Your own Anthropic API key, pasted in the app and stored encrypted on this computer. Usage is billed to your key; Lamplight Nook charges nothing extra.
- On Claude Max, Ultra or Team? The monthly Claude API credits that come with your plan work in Lamplight Nook too: link them to a Claude Console organization in your claude.ai billing settings, then use an API key from that organization.

### Privacy

Lamplight Nook collects none of your data: no analytics, no ads, and no servers of ours. Your settings, key and work stay on your computer.

Commissions are sent to Anthropic through Claude Code with your own key. If you tick a connection on a commission slip, what the staff read in the synced folder and the calendar goes with it. A connected calendar is fetched from this computer at the address you gave.

Sharing a work or sending a postcard saves a file that you pass on yourself. A shared work carries the work alone, with folder paths and anything like a key wiped. A postcard carries only how your shop looks and the name you go by.

The home-network switch is off by default. When it is on, only phones and computers you have paired can connect, every message is encrypted, and nothing goes through a server of ours.

- A damaged data file is no longer written over. The shop goes back to the last copy and tells you.

- The staff walk around the furniture, what you make shows up in the shop, and new neighbours drop in.
