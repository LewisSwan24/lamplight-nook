## 小灯屋 0.9.0

这一版第一次接上真实的 Claude Code 从头到尾跑过（2.1.306 和 2.1.317），修好了只有真跑才会出现的问题，也为上架 Microsoft Store 做好了准备。

**真实运行里修好的**
- 黑板上的计划回来了：新版 Claude Code 改用 TaskCreate / TaskUpdate 记待办，以前的版本认不出来，黑板上从来看不到真正的计划。现在黑板、角落小窗和托盘都会跟着它一项项打勾（旧版的 TodoWrite 也照样认）。
- 少了不必要的“需要你确认”：像 `node check.js 2>&1 | tail -30`、`node check.js; ls`、先 `cd` 进委托文件夹、用 here-document 写文件这类日常命令，现在一段一段地看，各段都安全就直接做。删除文件、写到文件夹外面、看不懂的写法（`$(...)`、变量、后台任务）仍然先问你；`find` 带 `-delete` / `-exec` 也会先问。删除确认按钮只列出真正要删的文件。
- 一次委托只收一次工：帮手和长命令不再被放到后台，避免帮手还没回来，店里就先喊“做好了”。
- 英文欢迎语里的 “Adeng” 改回 Wick。

**升级与商店**
- 升级不丢东西：数据文件夹有了版本号，旧数据在启动时自动升级，先在 `backup/` 留一份原样。0.5、0.6 时做完的委托也会算进小店的成长。
- 会检查 Claude Code 的版本：太旧会在柜台说明，可以“帮我更新”或“先这样用”。
- “写信给我们”和“内容有问题？告诉我们”：打开你自己的邮件程序，信写好了你来发，小灯屋什么都不替你发送。
- 商店版不运行任何安装脚本，只给出官方步骤和复制按钮。
- 订阅了 Claude Max 或 Team 的话，方案每月附带的 Claude API 赠送额度也可以用在小灯屋：在 claude.ai 的账单设置里把额度关联到一个 Claude Console 组织，再用这个组织创建的 API Key 就行。

**安装**
- `Lamplight-Nook-Setup-0.9.0.exe`：网站安装包（未签名，SmartScreen 里点“更多信息”→“仍要运行”）。
- `Lamplight-Nook-0.9.0-test.msix`：商店测试包，测试发布者，Windows 11 上用 PowerShell 安装：`Add-AppxPackage -AllowUnsigned .\Lamplight-Nook-0.9.0-test.msix`。

## Lamplight Nook 0.9.0

The first version run end to end against a real Claude Code (2.1.306 and 2.1.317), with the problems only a real run shows fixed, and ready for the Microsoft Store.

**Fixed from real runs**
- The plan is back on the blackboard: Claude Code now keeps its to-do list with TaskCreate / TaskUpdate, which earlier versions of the shop did not read, so a real run never showed its plan. The blackboard, the corner window and the tray now tick it off item by item (TodoWrite still works).
- Fewer needless confirmations: everyday commands such as `node check.js 2>&1 | tail -30`, `node check.js; ls`, a `cd` into the commission folder first, or writing a file with a here-document are read part by part and run when every part is safe. Deleting files, writing outside the folder, and anything the shop can't read (`$(...)`, variables, background jobs) still wait for you; so does `find` with `-delete` or `-exec`. The delete button names only the files really being deleted.
- One commission, one result: helpers and long commands are no longer sent off in the background, so the shop never says "done" while a helper is still out.
- The English welcome said "Adeng"; it is Wick.

**Upgrades and the Store**
- Upgrades keep everything: the data folder has a version, older data is brought up to date at start, with a copy kept in `backup/` first. Commissions finished under 0.5 and 0.6 now count towards the shop's growth.
- Claude Code's version is checked: an old copy is explained at the counter, with "Update it for me" or "Use it as it is".
- "Write to us" and "Something not right in this? Tell us" open your own mail program with the letter started; you send it, the shop sends nothing.
- The Store build never runs an installer script; it shows the official steps and a copy button.
- On Claude Max or Team? The monthly Claude API credits that come with your plan work in Lamplight Nook too: link them to a Claude Console organization in your claude.ai billing settings, then use an API key from that organization.

**Install**
- `Lamplight-Nook-Setup-0.9.0.exe`: the website installer (unsigned; in SmartScreen choose "More info", then "Run anyway").
- `Lamplight-Nook-0.9.0-test.msix`: the Store test package with a test publisher; on Windows 11, in PowerShell: `Add-AppxPackage -AllowUnsigned .\Lamplight-Nook-0.9.0-test.msix`.
