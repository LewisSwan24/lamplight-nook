## 小灯屋 0.9.1

一个安全修复，建议所有人更新。

- **`node -e` 不会再不打招呼就运行了。** 为了让 `node check.js` 这类检查脚本直接运行，`node` 以前整个算作安全命令，结果 `node -e "..."`、`node -p`、`node -r`，以及用管道或 here-document 交给 node 的代码，也都会不问你就运行。现在只有委托文件夹里的脚本文件照常运行；临时写的一段代码会和其他要紧的步骤一样，先等你确认（默认“先不要”）。
- `npx` 会下载并运行一个工具包，现在会先问你，和安装依赖一样。
- 订阅了 Claude Max、Ultra 或 Team 的话，方案每月附带的 Claude API 赠送额度也可以用在小灯屋：在 claude.ai 的账单设置里把额度关联到一个 Claude Console 组织，再用这个组织创建的 API Key 就行。

**安装**
- `Lamplight-Nook-Setup-0.9.1.exe`：网站安装包（未签名，SmartScreen 里点“更多信息”→“仍要运行”）。直接装在旧版上面即可，数据都会保留。
- `Lamplight-Nook-0.9.1-test.msix`：商店测试包，测试发布者，Windows 11 上用 PowerShell 安装：`Add-AppxPackage -AllowUnsigned .\Lamplight-Nook-0.9.1-test.msix`。

## Lamplight Nook 0.9.1

A safety fix; everyone should update.

- **`node -e` no longer runs unasked.** So that check scripts like `node check.js` run straight away, `node` used to count as a safe command as a whole, which also let `node -e "..."`, `node -p`, `node -r`, and code piped or given to node through a here-document run without asking you. Now only a script file in the commission folder runs as before; code written on the spot waits for you like any other serious step (the default is "not now").
- `npx` downloads and runs a package, so it now asks first, as an install does.
- On Claude Max, Ultra or Team? The monthly Claude API credits that come with your plan work in Lamplight Nook too: link them to a Claude Console organization in your claude.ai billing settings, then use an API key from that organization.

**Install**
- `Lamplight-Nook-Setup-0.9.1.exe`: the website installer (unsigned; in SmartScreen choose "More info", then "Run anyway"). Install it over the old version; your data stays.
- `Lamplight-Nook-0.9.1-test.msix`: the Store test package with a test publisher; on Windows 11, in PowerShell: `Add-AppxPackage -AllowUnsigned .\Lamplight-Nook-0.9.1-test.msix`.
