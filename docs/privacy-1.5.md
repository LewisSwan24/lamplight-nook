# 1.5 往外发的东西带什么

1.5 有三样东西会离开这台电脑：分享出去的作品、明信片、家里网络里给配对设备看的那个网页。前两样是文件，由用户自己存下来、自己发给别人，小灯屋不替用户上传。第三样只在家里的网络里，默认关着。我们还是没有服务器。

这份文件列出前两样里带什么、不带什么，再把微软商店政策里管隐私和用户发布内容的条款逐条对一遍（E6，2026-11-22）。`tests/goes-out.test.ts` 把两种文件都拆开查过。

## 1. 分享出去的作品

作品架上的“分享”，有 PDF、单个网页、原样、压缩包四种格式（E2）。

| 带 | 不带 |
|---|---|
| 作品本身：主文件，网页用到的图片、样式和脚本 | 委托单、店员的笔记、录制、花费：这些在数据目录里，从来不在作品文件夹里 |
| 用户交给店里的材料（`materials/`），作品常常用到它 | 整理文件夹时给店员的那份清单（`file-list.txt`）：压缩包里拿掉（E6） |
| 作品里写着的普通链接 | 从网盘文件夹读进来的文件（`from-synced-folder/`）：压缩包里拿掉（E6） |
| | 文字里出现的作品文件夹路径、用户主目录、像 Key 的字符串：都抹掉 |
| | 网页从网上或从作品文件夹外面加载的东西：单个网页里去掉，PDF 打印时不让加载 |

已知的一处：PDF 是把网页打印出来的。页面上要是写着文件夹路径，会跟着印进去，这一步不抹（E2 记过）。

## 2. 明信片

记事本里的“寄一张明信片”，存成一个 `.nook` 文件（E3）。

| 带 | 不带 |
|---|---|
| 设置里的称呼，最多 40 个字 | 作品、委托、委托单上的话、花费 |
| 主店是哪间，两间店的摆设 | 任何日期：长出来的东西和讲过的故事都不记哪天 |
| 店里长出来的东西的编号 | Key、作品文件夹、用户主目录 |
| 做完的委托数，街上三间店各做了几单 | 连接：网盘文件夹、日历地址、邮件草稿 |
| 每个街坊讲到第几章 | 家里网络的设置和配对过的设备 |

打开别人的明信片只当数据读：超过 64 KB 不读，键、编号和范围有一样不对就不打开。看明信片的窗口只能读明信片和回家，碰不到自己店里的东西。

## 3. 微软商店政策

对的是 7.20 版，2026 年 9 月 15 日发布，10 月 22 日生效。10.5 那几条读的是原文。11.x 那几条只读到了摘要，不是原文。提交前 Lewis 在 Partner Center 里还要再看一眼。

| 条款 | 说的是什么 | 1.5 的情况 | 结论 |
|---|---|---|---|
| 10.5.1 | 访问、收集或传送个人信息的，要有隐私政策，网址填进 Partner Center | 我们不收集。委托由用户用自己的 Key 发给 Anthropic，这一点 1.0 起就有 | 仓库里没记隐私政策的网址。提交 1.5 时 Lewis 核对 Partner Center 里有没有、写没写到分享、明信片和家里网络 |
| 10.5.2 | 把用户的个人信息发给外面，要用户在界面上同意，以后能撤回 | 分享和明信片都是用户自己点、自己存、自己发。家里网络默认关，打开要在设置里拨开关，随时能关 | 符合 |
| 10.5.3 | 别人的个人信息给第三方，要那个人同意 | 小灯屋不替用户把东西给任何人。E5 加了别的人连进同一间店以后，要再看他们能看到什么 | 1.5 现在符合；E5、E7 再对一次 |
| 10.5.4 | 个人信息要安全地存、安全地传 | 家里网络的消息用配对时的钥匙加密（tweetnacl secretbox）。网页本身是明文 HTTP 送到手机的，E7 会写成已知的限制 | 消息符合，网页这一处留给 E7 |
| 10.5.5 | 健康、财务这类敏感信息 | 不收集 | 不适用 |
| 10.5.7 | 位置 | 不用位置 | 不适用 |
| 10.5.8 | 儿童的个人信息 | 不收集 | 不适用 |
| 11.12 | 有用户发布内容的，要有内容守则、举报的办法，微软要求时能下架 | 没有托管，没有店内的公开分享，文件由用户在店外自己传。明信片里唯一的自由文字是 40 个字以内的称呼，收到的人自己选择打开，随时能关 | 不算用户发布内容的平台，不加举报流程。**暂定**，提交时如审核另有看法再改 |
| 11.11.3 | 用户发布内容可能抬高年龄分级的 | 同上 | 不适用 |
| 11.16 | 实时由 AI 生成内容的，要让用户能举报不当的输出，开发者要处理 | 店员的话和作品都是 Claude 生成的。这条和 1.5 无关，1.4 就该对。店里有“写信给我们”（`app/main/feedback.ts`），够不够算举报，没核 | 记进 plan-1.5 第 7 节，留给 E8 或 Lewis 决定 |

## 4. 商店说明

`store/listing.md` 的隐私那一段，中英文都加了两段。一段说分享和明信片是用户自己发出去的文件，各带什么。另一段说家里网络的开关默认关，只认配对过的设备，消息加密，不经过我们的服务器。
