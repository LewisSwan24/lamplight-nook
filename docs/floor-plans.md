# 两个场景的平面

坐标是 320×180 画布上的像素，脚的位置。数据在 `app/renderer/game/layout.ts` 的 `SEATS` 和 `STUDY_SEATS`，家具在 `assets/sprites/pieces.json`。

## 小店

| 谁 | 平时在哪 | 为什么 |
|---|---|---|
| 阿灯 | 柜台后面（228, 84） | 店主招呼客人的地方。站在咖啡机左边，柜台挡住腿，脸不被挡。 |
| 小橘 | 去黑板、去窗边、去前门跑腿 | 跑腿的人，要走得开。 |
| 老石 | 工作台旁边（182 以内的角落） | 工作台是他的地方。 |
| 青黛 | 黑板右侧（116, 62） | 要往黑板上贴配色，面朝房间。 |
| 小猫 | 窗边，有事去柜台外侧（226, 104） | 阿灯在柜台后面，蹭腿只能蹭客人。 |
| 客人、玩家 | 柜台右端（285, 90） | 正对阿灯，不挡在阿灯前面。 |
| 玩家等候 | 落地灯旁的椅子（262, 166） | 灯下读书的位置，离前门近。 |

**开会时四个人都坐下：** 阿灯和小橘坐桌子两头的椅子，老石和青黛坐长凳，侧身面对面。

**放在柜台上的东西：** 委托单在柜台左侧，开工时铃在最左端，杯子在咖啡机右边。

## 书房

书房和小店共用门、窗、黑板和工作台，下面几处不同：

| 东西 | 位置 | 为什么 |
|---|---|---|
| 书桌 | 两件拼成，中间有 3 像素的缝 | 阿灯改站（232, 84），其他人也都靠着一件站，不站在缝上。 |
| 沙发 | 移到阅读桌正下方（129, 106） | 开会时老石和青黛坐这里，四个人还是围着同一张桌子。 |
| 青黛在书桌旁 | 站到书桌右侧（285, 84） | 书桌右半边又高又宽，站在后面会被挡掉大半。 |

## 走路的规则

- 家具分成“占地”和“挡人”两部分。走路只绕开占地的部分，所以人能走到桌子、柜台后面，被挡住一部分。
- 节日摆设全年都算障碍，路线不随季节变。
- 算路见 `app/renderer/game/path.ts`。测试枚举所有角色和目标，见 `tests/routes.test.ts`。
