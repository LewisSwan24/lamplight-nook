# 1.1 真机清单：声音、讲述人、缩放

road-to-1.1.md 里 A3 的一项。用安装好的 1.1 在 Windows 上逐项过，结果栏写“过”，或者“不过，现象是什么”。清单只列应用里真有的东西，来源是 `app/renderer/audio/mix.ts`、`app/renderer/audio/sound.ts` 和 `app/renderer/ui/` 下的各张卡。

## 1. 声音

音效在 `assets/audio/`，音乐在 `assets/audio/music/`。音量先放在 70，不静音。

| 声音 | 什么时候响 | 怎么听 | 结果 |
|---|---|---|---|
| `click` | 点任何按钮 | 点工具栏的按钮。点开卡片的那一下只响 `open`，不该叠一声 `click` | |
| `open` | 卡片打开，或者往委托单里递了材料 | 打开委托单、作品架、笔记本、设置 | |
| `close` | 卡片收起 | 关掉上面几张卡 | |
| `ask` | 阿灯问问题的卡片弹出，或者设置里拖完音量松手 | 跑一单会提问的委托；拖一下音量滑杆 | |
| `serious` | 要紧的确认卡弹出 | 跑一单会删东西的委托。响的时候音乐停下，别的音效都不响 | |
| `success` | 委托做完；设置里 Claude Code 那一行变绿 | 跑完一单 | |
| `fail` | 委托没做成 | 跑一单会失败的委托，或者断网再跑 | |
| `door` | 有人进出店门 | 看帮手出门、回来。1.5 秒内不重复 | |
| `mallet` | 有人敲锤子，连敲三下 | 委托做到动手的那一步。6 秒内不重复 | |
| `pencil` | 有人写字 | 委托做到写的那一步。8 秒内不重复 | |
| `ding` | 按铃开会 | 委托进行中点柜台上的铃 | |
| 背景音乐 | 店开着就放，十首轮流 | 听一首放完换下一首；清晨、白天、傍晚、夜里音量依次不同，夜里最轻 | |
| 静音按钮 | 工具栏 | 点了以后音效和音乐都没有，再点恢复 | |
| 音量滑杆 | 设置 | 拖动时音乐跟着变，松手后重开应用还是这个音量 | |

## 2. Windows 讲述人

按 `Ctrl + Win + Enter` 打开讲述人，只用键盘走。每一项看三件事：打开时读不读，读的顺序对不对，按钮有没有名字。

| 地方 | 要听的 | 结果 |
|---|---|---|
| 工具栏 | 读出工具栏的名字。委托、进度、作品架、笔记本、字幕、声音或静音、设置，每个按钮都有名字，顺序和画面一致 | |
| 欢迎卡 | 第一次开店时读标题和说明，填 Key 的框有名字 | |
| 还没准备好的卡 | 读出缺什么，每个按钮有名字 | |
| 试用结束的卡 | 读出说明和按钮 | |
| 委托单 | 每种模板、每个输入框、递材料和开工的按钮都有名字，焦点从第一个能填的地方开始 | |
| 计划卡 | 按顺序读出每一步 | |
| 进度卡 | 读出用了多久、上限多少，开会和人物的按钮有名字 | |
| 提问卡 | 读出问题和每个选项，按 1 到 4 能选 | |
| 要紧的确认卡 | 读出要做什么、为什么要紧，两个按钮有名字 | |
| 结果卡 | 读出做成了什么，打开、再改改等按钮有名字 | |
| 失败卡和预算卡 | 读出标题和说明；预算卡的“接着做”和“看看已经做好的”有名字 | |
| 没做完的委托卡 | 读出说明，接着做的按钮有名字 | |
| 人物卡 | 点店里的人或猫，读出名字和在做什么 | |
| 开会卡、再改改卡 | 读出提示，输入框和按钮有名字 | |
| 作品架 | 读出卡片名字，每件作品的名字和按钮都读；“带走”以后的压缩包、PDF 两个按钮有名字 | |
| 笔记本 | 读出卡片名字，再按顺序读账本、小店的日子、委托记录和卡住的事 | |
| 数据出问题的卡 | 读出出了什么问题和按钮 | |
| 字幕记录 | 读出卡片名字，按时间顺序读字幕 | |
| 设置 | 每一项有名字，音量滑杆读出数值，账本的月份能展开 | |
| 更新的信 | 读出版本号和更新内容，“更新”按钮有名字 | |
| 搬家的问题卡 | 读出作品数和钱数，“搬过来”和另一个按钮有名字 | |
| 关卡片以后 | 焦点回到打开它的那个按钮 | |
