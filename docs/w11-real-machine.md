# W11 真机验证清单

这份由 Lewis 在自己的电脑上照着做。真实 Claude Code 用应用里存的 Key，总额按 $2.20 控制。

## 花钱的规矩

- 开始前，在 Anthropic Console 记下当前用量。结束后再看一次，那才是真实花费。
- 在设置里把每一轮上限调到 $1，这是最低档。
- 每做完一步，看一眼设置里本月花了多少。过了 $2.20 就停，剩下的步骤告诉我再定。
- 应用的上限是每一轮 $1，不是总额，所以 $2.20 要靠你看着。叫停和杀进程那两单的花费，账本可能记不全，这正是要查的事。

## 一、安装

1. 运行 `dist` 里的安装程序，装好后打开。
2. 看店里是不是原来的数据：名字、书架上的作品、小本子。

## 二、花钱的四步

3. **做一单。** 选“示范：记账小页面”，一直做到结果卡出来。记下卡上的金额。
4. **再改一轮。** 在结果卡点“再改改”，提一个很小的改动，比如把标题换个说法。记下新金额。预算卡或结果卡上的金额应该是两轮加起来的总数，Console 也应该对得上。
5. **叫停一单。** 再递一单很小的委托。店员开始干活后关窗口，选“停下并关闭”。重新打开应用，看本月金额有没有变，再和 Console 比一比。店里问要不要接着做时，选不接着做。
6. **杀掉应用。** 再递一单很小的委托。店员开始干活后，在 PowerShell 里运行下面两条。它只动小灯屋自己的进程，等最多两分钟，留下的进程会被它停掉。把最后的 `RESULT` 那行发给我。

   ```powershell
   cd C:\Users\LewisDong\Projects\lamplight-decisions
   node tools/real/kill-watch.mjs
   ```

## 三、不花钱的几件事

7. **听声音。** 打开声音，听一遍音效和音乐，有没有刺耳、太响或者没声音的。
8. **读屏软件。** 按 `Win + Ctrl + Enter` 打开讲述人，走一遍：打开委托单、填写、回答一张决策卡。听念出来的话是否说得通。这一步不用真的递单。
9. **屏幕缩放。** 系统设置里切到 125% 和 150%，看画面清不清楚。有第二块缩放不同的显示器的话，把窗口拖过去看看。
10. **挪走的作品。** 把一件作品的文件夹挪到别处，在书架上把新位置指给店里。这一步到“再改改”之前都不花钱，要真的改一轮就算进总额。
11. **`ELECTRON_RUN_AS_NODE`。** 在 PowerShell 里运行下面三条。正常情况是打不出 `node-ok`。

    ```powershell
    $env:ELECTRON_RUN_AS_NODE = "1"
    & "$env:LOCALAPPDATA\Programs\Lamplight Nook\Lamplight Nook.exe" -e "console.log('node-ok')"
    Remove-Item Env:ELECTRON_RUN_AS_NODE
    ```

    如果应用窗口打开了，直接关掉就行。

## 四、微软商店的包

12. 我打好测试用的 MSIX 后，你装上打开，看能不能启动，以及能不能看到现有数据。看不到也要记下来，这决定发布说明怎么写。

## 记什么发给我

- 第 3、4、5 步的金额，和 Console 上的总数。
- 第 6 步的 `RESULT` 那行。
- 其他步骤只说哪里不对，没问题的说一声“都正常”就行。
