# 1.7 的美术清单

`docs/plan-1.7.md` 各包要加的图记在这里，写法照 `docs/art-1.6.md`：每张图从哪个素材包拼出来，还是手画，由哪个脚本做。素材包和授权见 `docs/art.md`。

`tests/art-sources.test.ts` 把这份清单和 1.4、1.6 的两份一起读。

## 改了的旧图

这几张在前面的清单上，1.7 只是往里加东西，出处没变：

- `town-decor.png`（G1）：加了元宵门上的一串小灯笼、端午门两边的艾草、中秋门口的兔子灯和春节空地上的春联摊，都是 `scripts/art/decor.py` 手画的。
- `garden-crops.png`（G2）：后面接了六格冬天的菜，用 Modern Farm 的白菜、洋葱和菜花的生长图。
- `bakery.png`（G2）：黑板上的价目拿掉了，换成下面那张随季节换的菜单。
